# crazyFlappy

Juego desarrollado con **Java + libGDX**.

CrazyFlappy es una parodia un tanto "especial" del famoso juego *Flappy Bird*.

Consta de **4 niveles**, cada uno más difícil que el anterior. El objetivo es sobrevivir mientras esquivas enemigos. Cuanto mayor sea la dificultad, más tiempo tendrás que aguantar con vida.

Si no te convence esta fantástica descripción, siempre puedes echar un vistazo a la demo:

[Ver demo en YouTube](https://www.youtube.com/watch?v=-QF498A850o) (perdón por los tacos)

![Flappy Bird](https://programamos.es/web/wp-content/uploads/2016/10/flappybird.jpg)

## Cómo jugar

Si quieres probar el juego, entra en la carpeta `jar/` y ejecuta el archivo `crazyFlappy.jar`.

## Requisitos

- Java Runtime Environment (JRE) 8.
